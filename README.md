# Velnora

**The Modern Commerce Platform**

Fresh, clean rebuild. The architecture will be expanded in tested layers: storefront, authentication, database, seller workspace, admin console, products, inventory, orders, fulfillment/dropshipping, recommendations and analytics.

## Deployment

Deploy this repository directly with Vercel using the repository root as the Root Directory.

## Rule

No credentials in source control. Each major layer must remain buildable before the next layer is added.
